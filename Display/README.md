# Display 

### Definition
A display is an output device that shows text, images, graphics, or video generated by a computer.

Computer Graphics uses different output/display devices, such as:

- Cathode Ray Tube (CRT)  
- Vector or Random Scan Display  
- Raster Scan Display  
- Colored Monitors  
- LED, LCD, and TFT Screens  
---

# Cathode Ray Tube (CRT)

CRT is one of the most common display devices.


### Main Features of CRT
- It has a vacuum glass tube.  
- It uses very high voltage.  
- A filament produces heat.  
- Electrons move toward the anode and focusing cylinder.  
- Vertical and horizontal plates control the electron beam direction.  
- The electron beam hits the phosphor coating on the screen to produce light/images.  

# 🖥️ How CRT Works

- CRT converts electrical signals into visual signals.  
- Inside the electron gun, a heated filament releases electrons.  
- Electrons are focused into a sharp beam using an electromagnet.  
- The beam moves to specific points on the screen.  
- The screen is coated with phosphor dots.  
- When the electron beam hits the phosphor, it glows.  
- Brightness depends on the beam strength and hit time.  

---

## 📌 More About CRT
- The focusing system works like a camera lens to focus the beam on the screen.  
- Horizontal and vertical deflectors control beam movement.  
- The screen uses a special material called phosphor.  

In color CRTs, three phosphors are used:
- Red  
- Green  
- Blue  

---

## 💡 Light Production in CRT
- Electrons excite phosphor molecules on the screen.  
- The phosphor quickly emits light, called fluorescence.  
- Another slower light emission is called phosphorescence.  
- The glow fades within about 15–20 milliseconds.  
- So, the screen must refresh continuously to keep the image visible.  

---

## Phosphor Terms

### Fluorescence
Light produced while the phosphor is being hit by the electron beam.

### Phosphorescence
Light produced after the electron beam is removed.

### Persistence
The time taken for phosphorescence to decrease to 10% of its original brightness after excitation stops.

### High Persistence Phosphor
- Keeps glowing for a longer time.  
- Needs lower refresh rate.  
- Helps reduce screen flicker.  

### Low Persistence Phosphor
- Glow fades quickly.  
- Needs higher refresh rate.  
- Prevents flickering by refreshing the screen faster.

# 📺 CRT Display Technologies

There are two main types of CRT display technologies:

- Vector / Random Scan Display  
- Raster Scan Display  

---

# 📡 Vector Display

## 📌 System Components
A vector display uses:
- CPU  
- Display Controller  
- Display Buffer Memory  
- CRT  

The display controller works as an input/output device connected to the CPU.  

---

## 🗂️ Display Buffer
The display buffer stores display commands called the display list.

The display list contains:
- Point plotting commands  
- Line drawing commands  
- Character drawing commands  

---

## ⚙️ Working of Vector Display
- The display controller reads the commands and sends coordinates to the vector generator.  
- The vector generator converts digital coordinates into analog voltages.  
- These voltages control the electron beam movement on the CRT screen.  
- The beam moves directly from one point to another, so it is called Random Scan Display.  

---

## 🔄 Screen Refreshing
- When the beam hits the phosphor screen, light is produced.  
- The light fades after a few milliseconds.  
- So, the display list must be refreshed at least 30 times per second to avoid flickering.  
- Because it stores data for refreshing, the display buffer is also called the refresh buffer.  

---

## ✏️ Drawing Lines in Vector Display
- To draw a line between points P1 and P2, the beam moves directly from P1 to P2.  
- If no line is needed, the beam is turned off while moving.  

Beam movement requires:
- Magnitude information  
- Direction information  

This information is generated by the vector graphics generator.  

---

# 🖥️ Raster Display

## 📌 Components of Raster Display
Raster display consists of:
- CPU  
- Display Controller  
- Video Controller  
- Refresh Buffer  
- Keyboard  
- Mouse  
- CRT  

---

## 🗂️ Image Storage
- The image is stored in the refresh buffer as 1’s and 0’s.  
- The video controller reads the refresh buffer and shows the image on the screen.  
- The screen is scanned line by line from top to bottom.  

---

## ⚙️ Working of Raster Display
- Horizontal and vertical signals move the electron beam across the screen.  
- The beam moves from left to right while drawing.  
- During left to right movement, the beam is ON.  
- When the beam returns from right to left, it is OFF.  
- This return process is called Horizontal Retrace.  

---

## 🔄 Vertical Retrace
- After reaching the bottom of the screen, the beam turns OFF.  
- It quickly returns to the top-left corner.  
- This process is called Vertical Retrace.  

---

## 🧠 Frame Buffer and Pixels
- The image is refreshed continuously to keep it visible.  
- Frame Buffer is a special memory area used for graphics.  
- It stores intensity values for every screen point.  
- Data is displayed row by row on the screen.  
- Each screen point is called a Pixel (Picture Element or Pel).  
- Every pixel has its own row and column position.
