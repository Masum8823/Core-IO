# Display 

### Definition
A display is an output device that shows text, images, graphics, or video generated by a computer.

Computer Graphics uses different output/display devices, such as:

- Cathode Ray Tube (CRT)  
- Vector or Random Scan Display  
- Raster Scan Display  
- Colored Monitors  
- LED, LCD, and TFT Screens  
---

# Cathode Ray Tube (CRT)

CRT is one of the most common display devices.


### Main Features of CRT
- It has a vacuum glass tube.  
- It uses very high voltage.  
- A filament produces heat.  
- Electrons move toward the anode and focusing cylinder.  
- Vertical and horizontal plates control the electron beam direction.  
- The electron beam hits the phosphor coating on the screen to produce light/images.
