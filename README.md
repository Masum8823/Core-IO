# CoreIO

CoreIO is a structured repository for Computer Peripherals and Interfacing course notes.

This repository contains organized and easy-to-understand notes on:
- Motors and Motor Control
- Printers
- Display Technologies
- CRT, Vector and Raster Displays
- Keyboard and Mouse Interfacing
- Input and Output Devices
- Computer Peripheral Concepts
